The first public release of Avalok, published to npm as `avalok`. Run `npx avalok` in a repository.

- **Architecture map.** Static analysis of TypeScript and Python, plus Terraform, Kubernetes, Helm, Docker and Compose, shown as services and infrastructure with evidence and confidence levels. Nothing is executed.
- **Agent replay.** Codex sessions read from local files, and Claude Code through OpenTelemetry traces and opt-in hooks, replayed on the same canvas.
- **OpenTelemetry.** A local OTLP/HTTP receiver for protobuf and JSON traces, with OpenInference and GenAI semantics shown as agent activity.
- **Share.** `avalok recap` and the dashboard Share button produce a card, an interactive replay, an architecture diagram and Markdown for pull requests, generated and previewed locally.
- **Local-first.** Dashboard and receiver bind to `127.0.0.1` only. No account, analytics, crash reporting or update check.

Known limits are listed in [Limits](/docs/limits/).

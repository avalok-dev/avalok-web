- **Claude Code needs no setup.** Avalok reads the session files Claude Code already writes, read-only, and follows running sessions live. Hooks and OpenTelemetry are optional extras.
- **Clearer source picker.** Agents, sessions for this repository or all, architecture, and example repositories are grouped and labelled. Sessions show what they started with and whether they are running.
- **Live view.** Explains what to do when nothing is running, and opens a session that starts in your repository by itself.
- Sessions started in a parent folder of your repository are listed, and a running one opens on landing.
